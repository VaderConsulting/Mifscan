# Mifscan

CSC VB6 MIF serial scanner (project Project1). Walks selected directories for `Monitor.mif`, `PC.mif`, `compaq0.mif`, and `compaq2.mif`, extracts Serial Number fields, and lists Monitor Serial Number and PC Serial Number values with Refresh.

**Source last updated:** 2026-08-27 · **Language:** VB6 · **Target:** VB6 Win32 · **Output:** WinForms exe

_Note: original OneDrive LastWriteTime values were wiped to 2026-08-27 by a zip transfer; date above uses best available evidence (headers/copyright where helpful)._
